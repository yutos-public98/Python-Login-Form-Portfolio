# Python + SQL ログイン認証システム

## 概要

PythonのTKiterを使用してGUIログインフォームを作成し、SQLiteによるユーザー情報の登録・管理およびログイン認証を実装しました。

## 制作目的

Pythonエンジニア基礎試験の学習で身につけた基礎文法をもとに、実際のアプリケーション開発の流れを学ぶことを目的としてログインフォームを制作しました。

- Python標準ライブラリのインポートおよび活用
- Tkinterを使ったGUIの作成
- SQLiteによるデータベース操作
- SQLを使用したデータの登録・検索
- ユーザー認証
- 入力値のバリデーション
- SQLインジェクション対策
- パスワードのハッシュ化

## 使用技術

- VSCode
- Python3.14
- TKinter
- SQLite
- SQL

## プロジェクト構成と主な機能

- ユーザー登録
- メールアドレス・パスワードの入力チェック
- ログイン認証
- パスワードが間違っている場合のエラー表示
- SQLiteへのユーザー情報保存
- パスワードのハッシュ化

## プロジェクト構成

|ファイル名|機能|
|---|---|
|auth.py|認証処理|
|database.py|SQLiteを使ったデータベース|

|login_success.py|認証成功後の画面|

## 工夫した点・学んだこと

- 入力値検証で、未入力の状態で実行した場合に警告を表示するようにしました。

- SQL文に値を直接埋め込まず、プレースホルダーを介して値を渡すことで、SQLインジェクション攻撃を防いでいます

- パスワードをハッシュ化して保存することで、データベースに平文のパスワードを保存しない仕組みを実装しました。

## 今後の改善点

- 総当たり攻撃（ブルートフォース）を防ぐために、一定以上連続してログインに失敗した場合、一時的にログインを制限する仕組みを導入することが必要であると考えられます。

- パスワードの安全性を高めるために、最低文字数や文字種などの設定を導入することが必要と考えられます。

- パスワードの安全性を強化するために、現行のSHA-256によるハッシュ化から、より安全性の高いハッシュ化方式への変更を検討します。
